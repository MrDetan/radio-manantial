## ✨ Características de la Aplicación

- 🔴 **Streaming en Vivo:** Conexión directa y fluida a la señal de audio Shoutcast HD 128 kbps (`https://manant-megacaster.radioca.st/stream`).
- 🎶 **Metadatos y Carátulas Automáticas:** Detección en tiempo real del artista y alabanza que está sonando, con búsqueda de portadas oficiales en alta resolución.
- 📊 **Visualizador de Espectro (Ecualizador):** Animación reactiva en tiempo real con la paleta de color oficial Cian Eléctrico (`#04adf6`).
- ⏰ **Temporizador de Apagado (Sleep Timer):** Apagado gradual automático con presets de 15, 30, 45, 60 y 90 minutos para dormir escuchando la radio.
- 📱 **Diseño Móvil & Simulador:** Interfaz responsiva con marco de smartphone interactivo para pantallas de escritorio y vista inmersiva completa para teléfonos.
- 💬 **Interacción con Cabina:** Botón directo a WhatsApp oficial (`+52 668 228 8161`) y formulario para pedir oraciones y enviar saludos.
- 📴 **PWA (Progressive Web App):** Instalable en la pantalla de inicio de teléfonos Android como si fuera una aplicación nativa.
- 🔒 **Controles de Pantalla de Bloqueo (MediaSession API):** Control de reproducción y visualización de carátula en la barra de notificaciones del móvil.

## 🚀 Desarrollo Local

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor local de desarrollo
npm run dev

# 3. Compilar para producción
npm run build
```
